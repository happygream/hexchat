# Security Policy

## Reporting a vulnerability

Email security@hexchat.co.uk with a description of the issue, steps to reproduce, and the potential impact. Please do not open a public GitHub issue for security vulnerabilities.

I aim to respond within 48 hours. I ask that you give reasonable time to patch before any public disclosure.

## Scope

- hexchat.co.uk
- ws.hexchat.co.uk
- /api/*

## Out of scope

- Denial of service
- Social engineering
- Physical access attacks
- Third-party services (LiveKit, Cloudflare, Giphy, Metered)
